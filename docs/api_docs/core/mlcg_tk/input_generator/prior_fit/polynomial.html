polynomial module¶

mlcg_tk.input_generator.prior_fit.polynomial.fit_polynomial_from_potential_estimates(bin_centers_nz, dG_nz, n_degs=4, constrain_deg=4, regression_method='scipy', **kwargs)[source]¶

Loop over n_degs basins and use either the AIC criterion or a prechosen degree to select best fit. Parameter fitting occurs over unmaksed regions of the free energy only.

Parameters:

  • bin_centers_nz (Tensor) – Bin centers over which the fit is carried out

  • dG_nz (Tensor) – The emperical free energy correspinding to the bin centers

  • n_degs (int) – The maximum number of degrees to attempt to fit if using the AIC criterion for prior model selection

  • constrain_deg (Optional[int]) – If not None, a single fit is produced for the specified integer degree instead of using the AIC criterion for fit selection between multiple degrees

Returns:

Statistics dictionary with fitted interaction parameters
